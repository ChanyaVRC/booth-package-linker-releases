ショップ画面 ​

ライブラリの購入アイテムを ショップ単位 でまとめて見れる画面です。 さらに BOOTH の「フォロー中ショップ」を取り込んで、新作が出たら通知できます。

画面内のショップ名・ハンドルはデモ用の架空データです。

サブタブ ​

[すべて (87)] [★ フォロー中 (70)] [ライブラリ (45)]    [↺]
タブ内容
すべてライブラリ内 + フォロー中ショップ (= 購入無しでも見える)
★ フォロー中BOOTH 側でフォローしているショップだけ
ライブラリライブラリに購入アイテムがあるショップだけ

ショップカード ​

┌──────────────────────────────┐
│  ┌──┐ ショップ名 ✓           │  ✓: 公式検証済バッジ
│  │🏪│ @ハンドル               │
│  └──┘ 12 アイテム             │
└──────────────────────────────┘
   ★ ← フォロー中 (アイコン右下にバッジ)
  • フォロー中のショップはアイコン右下に ★ バッジ
  • ライブラリに購入アイテム 0 件のフォロー中ショップは「ライブラリ内 0 アイテム」と表示 (薄く表示)
  • クリックで ショップ詳細 (購入済みアイテムがある場合) または BOOTH を外部で開く (購入が無く、フォローのみの場合)
  • 一覧の並び順は フォロー中 → アイテム数の多い順 → 名前順

ショップ詳細画面 ​

ショップカードをクリックすると、そのショップから買ったアイテム一覧が出ます。

  • 大きいアイコン + ショップ名 + 「BOOTH で開く」ボタン
  • @ハンドルの横に 作者名 を表示 (例: @handle (うのいず))。BOOTH のショップページから取得し、約 30 日キャッシュします
  • 下に正方形のタイル一覧 (商品サムネ + 名前) で全購入アイテム
  • タイルクリックで 商品詳細画面 へ移動

R-18 表示との連動 ​

ライブラリ画面の R-18 表示 を OFF にすると、ショップタブにも反映されます。

  • 各ショップの アイテム件数 と 詳細のタイル一覧 から R-18 商品が除かれます
  • 全アイテムが R-18 のショップは一覧から消えます (フォロー中のショップは「ライブラリ内 0 アイテム」として残ります)

BOOTH フォロー機能 ​

「☆ フォロー」ボタン ​

ライブラリの商品カードを開いて出てくる ショップ詳細パネル (ショップ名クリック) には 「☆ フォロー」 ボタンがあります。

  • クリックで BOOTH 側にもフォローを反映
  • 同時に手元のデータにも追加
  • もう一度クリックでフォロー解除

一括同期 (↺ ボタン) ​

ショップタブの ↺ ボタンで、フォロー中ショップの一覧を同期し、新着商品を確認します:

  1. フォロー中ショップの名前とアイコンを取り込み、ショップカードを順次表示
  2. フォロー中ショップの新着商品を確認
  3. 完了メッセージに「新規 N 件 追加 / 既存 M 件 / 新着 K 件」を表示

同期中の手順と進み具合は バックグラウンドタスク で確認でき、そこから中止もできます。

自動同期 (起動時) ​

初回起動時や、最後の確認から設定した時間が経過したときは、起動後に自動で同期します。

「24 時間」は 設定 で変更できます (1〜168 時間 = 1 時間〜7 日)。

新着通知 ​

フォロー中ショップの新着商品を確認し、まだ確認していないものを通知ベルへ追加します。

  • 通知パネル (右下 🔔) に「🏪 ショップ名 新着」+ 商品名 + サムネ
  • 通知行クリックで BOOTH 商品ページを外部ブラウザで開く
  • 初回の取り込み時は通知を出しません

制限 ​

  • 1 回に同期できるフォロー中ショップは最大 1,000 件です
  • 新着確認は 1 回につき約 500 商品までです。前回の確認から 500 件を超える 新着があると、それより古い未確認の商品を取りこぼす場合があります
  • BOOTH 側でフォロー解除してもアプリの一覧には残ります。削除するには、ショップ詳細パネルの「★ フォロー中」を切り替えてください
