キーボードショートカット ​

設定画面の「キーボードショートカット」(折りたたみ) には、割り当てを変更できる 操作の現在値と、主な固定操作の一覧があり、 ライブラリ画面で Shift / Ctrl / Alt を押すと該当組み合わせのヒントが 画面左下にも出ます (= 修飾キーヒント)。

全体の移動 ​

キー動作
Alt + ←戻る (履歴 1 つ前へ)
Alt + →進む (戻った先から再度進む)
マウスの戻るボタン戻る
マウスの進むボタン進む
Shift + ←前のトップタブへ (ライブラリ / ショップ / スキリスト / 設定 をループ)
Shift + →次のトップタブへ (ループ)
Ctrl + Shift + ←現在の画面の前のサブタブへ (ループ)
Ctrl + Shift + →現在の画面の次のサブタブへ (ループ)
Escダイアログ / 検索ボックス / プレビュー を閉じる
Ctrl + Fライブラリ画面の検索ボックスへ移動

履歴は タブ + 詳細画面 を横断する 1 本の流れで管理しています。 ショップタブから商品詳細に飛んでも、戻ると元のショップに帰ります。

ライブラリ画面 (グリッド) ​

キー動作
←/→/↑/↓カード間の移動 (フォーカス)
Home / End先頭 / 末尾のカードへ
Enterフォーカス中のカードの詳細を開く
Del確認なしでゴミ箱に移動 (通知の「元に戻す」で復元可)
Ctrl + クリック一括選択モード ON + このカードを選択
Shift + クリックBOOTH 商品ページを外部ブラウザで開く
Ctrl + 右クリックこの商品の未取得ファイルをダウンロード (非公開・対象外の旧版は除く)
Ctrl + Shift + 右クリックこのアイテムをゴミ箱へ (= すぐにゴミ箱へ)

一括選択モード ​

キー動作
クリック選択の切替 (修飾キー無視)

商品詳細画面 ​

左ペインのファイル一覧 (フォルダー / Unity Package タブ) と、右ペインのフォルダ内容を キーボードだけで操作できます。

キー動作
↑ / ↓ファイル一覧の行カーソルを移動 (まだ選択はしない)
Enterカーソル中の行を選択 (右側に情報・プレビューを表示)
← / →左ペインのタブを切替 (フォルダー ↔ Unity Package)
Shift + ↑ / ↓複数選択できるリストで範囲選択
Ctrl + Aリストを全選択
メニューキー選択行の操作メニュー (ダウンロード / 削除 / コピー / まとめて import など)
Esc履歴の 1 つ前へ戻る (履歴がなければライブラリへ戻る)
Alt + ← / マウスの戻るボタン戻る (履歴)

これらはすべて設定の「ショートカットの変更 > 詳細画面」で割り当て直せます。 グリッドと詳細は別画面なので、両方で ↑↓ などの同じキーを使っても衝突しません。

修飾キーヒント ​

ライブラリ画面で Shift や Ctrl を押すと、画面左下に 「このキーで何ができるか」のヒントが動的にポップアップします。

  • 例: Ctrl 押下中 → Ctrl + クリック → 選択モード, Ctrl + 右クリック → 未取得ファイルをダウンロード
  • 修飾キーを押している間だけ表示され、離すと消えます

カスタマイズ (割り当て直し) ​

設定タブの「キーボードショートカット > ショートカットの変更」から、 キーボード / マウス操作を自由に割り当て直しできます。

  1. 変更したいコマンドの行をクリック
  2. 新しいキー操作 (またはマウス操作) を押す
  3. 確定 — 既に使われているキーには割り当てできません (警告が出ます)
  • Esc: 割り当て直しをキャンセル
  • ↺ ボタン: そのコマンドをデフォルトのキーに戻す
  • 方向キー (←/→/↑/↓) を含め各コマンドは割り当て直せます (「グリッド / スキリスト」「ライブラリのグリッド」「選択モード」 「詳細画面」「全体」のセクション別に一覧表示されます)

設定タブの「ショートカット一覧」(折りたたみ) には現在の割り当てが一覧表示されます。
