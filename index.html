ライブラリ一括取得

BOOTH の購入・ギフト・無料ダウンロードをまとめて取得。ZIP は既定で自動展開し、設定で ZIP のまま保存することもできます。

🔗

ブラウザから直接ダウンロード

ブラウザの BOOTH ページから専用リンクで 1 クリック直送。既定では受信後にダウンロードを開始し、設定で登録だけにもできます。

🏪

ショップ別表示

購入アイテムをショップ単位で一覧。BOOTH のフォロー中ショップを自動取り込みし、新作が出ると通知ベルで知らせます。

🔖

スキリスト連携

BOOTH のスキリストをそのままアプリ側にも反映。購入済みかどうかもバッジで確認できます。

🔁

ストレージ最適化

同じ中身のファイル・フォルダや旧バージョンを安全に整理。完全一致は 1 件を保持し、旧版は確認してから削除できます。

📦

Unity プロジェクトに直接取り込み

起動中の Unity プロジェクトに .unitypackage を直接取り込み。Unity 拡張のインストールは不要。複数のプロジェクトを開いていれば、取り込み先を選べます。

どんなソフト？ ​

BOOTH Package Linker は BOOTH で買った VRChat / Unity 向けアセットを 1 つの Windows デスクトップアプリで管理するためのツールです。

主にこういう使い方を想定しています:

  • BOOTH で買ったものを 一括ダウンロード して 1 つのフォルダに整理する
  • ブラウザの BOOTH ページから専用リンクで追加し、設定に応じて そのままダウンロード
  • 過去に買ったアイテムを 検索 / 絞り込み / カスタムカテゴリ付け して再発見しやすくする
  • 完全重複や旧バージョン を見つけてディスクを掃除する
  • フォロー中ショップの 新作 に気付く

公式ツールではない ​

このアプリは BOOTH (pixiv 株式会社) の公式ツールではありません。 BOOTH 側の仕様変更で動かなくなる可能性があります。

  • 初めて使う方は インストール から
  • 画面ごとの使い方は ライブラリ画面 など各ページを参照
  • キー操作は キーボードショートカット にまとめてあります
